# GillNet AI

GillNet AI is an AI-powered cybersecurity platform designed to detect phishing websites, scam messages, and weak passwords while providing intelligent security recommendations.

## Features

- Phishing URL Detection
- Scam Message Analysis
- Password Strength Checker
- AI Cybersecurity Assistant
- Security Recommendations
- Scan History Dashboard

## Tech Stack

- Frontend: HTML, CSS, JavaScript (React later)
- Backend: Java + Spring Boot
- Database: MongoDB Atlas
- AI: Hugging Face Models + Gemini/OpenAI APIs
